Agronomy Research Trial Database Guide

Welcome to the PalmnexReaDS reference manual. This documentation outlines the standards, conventions, and database procedures established by the Palm Oil Research Institute of Malaysia (PORIM) for recording and managing oil palm trial datasets.

View Full PDF Manual
Module 1

List of Available Trial Data

Master registry of all research stations (Kluang, Teluk Intan, Jerantut, Sabah).
  • Displays data availability from 1988 through 1998+.
  • Tracks annual indicators for Yield, Leaf, Veg, and Soil.
  • Filter by trial code, research station, or status.

Module 2

Trial Main Information

Detailed agronomic metadata for individual field experiments.
  • Trial code structure (Station prefix + Trial number).
  • Experimental design, treatments, replicates, and plot allocations.
  • Palm numbering conventions and block layouts.

Module 3

Yield Recording Program

Fresh Fruit Bunch (FFB) harvesting data collection protocols.
  • 10-day to 14-day field harvesting rounds.
  • Individual palm bunch counts and bunch weight recordings.
  • FFB tonnage and mean bunch weight calculation engines.
Open Yield Program →
Module 4

Vegetative Field Sampling

Morphological vegetative growth assessment methodologies.
  • Frond 17 sampling protocols.
  • Petiole cross-section (PCS) & rachis length.
  • Leaf Area Index (LAI) and annual height increment measurements.
Open Vegetative Sampling →
Module 5

Annual Plot Data Summaries

Aggregated annual agronomic performance and nutritional analysis.
  • Yearly FFB totals per palm and per hectare.
  • Leaf tissue nutrient concentrations (N, P, K, Mg, B).
  • Nutrient response curves and ANOVA-ready aggregations.
Open Annual Plot Data →
Security

Supabase & Data Sync

Secure synchronization between offline research tablets and cloud database.
  • Automatic local caching for field operations with no cellular connectivity.
  • Bi-directional cloud synchronization when returning to station Wi-Fi.
  • Role-based permissions for Lead Agronomists and Field Officers.
